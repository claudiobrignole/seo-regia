Business model

Biography Library is a nonprofit association. We advertise only our own websites with Google Ad Grants. We do not run an agency and we do not manage ads for other organisations.

Websites in scope:

  • https://biographylibrary.org
  • https://app.biographylibrary.org (same organisation; ads land on the main site unless we change that later)

A separate commercial activity (Brignole) has its own Google Ads accounts and its own developer token. This token will not access those accounts. Grants spend and paid spend are never combined.

The association’s public websites must not carry visitor-tracking scripts (no Google Analytics, Tag Manager, or ads pixels on the pages), by statute. Search Console is verified with DNS only. Conversion recording uses a first-party WordPress plugin that stores the Google click id from the landing URL when someone submits a contact form. No Google JavaScript is loaded on the site.

Tool access / use

The tool is Regia SEO, a private panel for one operator.

  • No public sign-ups. No third-party users. No agency access.
  • Reads campaign performance (impressions, clicks, CTR, keywords) once per night.
  • Prepares campaign drafts in the panel. Live campaigns are created by hand in the Google Ads interface.
  • Does not create, pause, enable, or mutate campaigns, ads, budgets, or keywords through the API.
  • Does upload click conversions for form submissions that followed an ad click (gclid), using ConversionUploadService. No CSV is uploaded by hand.
  • On first run, the tool may enable auto-tagging and create one conversion action of type UPLOAD_CLICKS if it is missing. That is the only other write.

We apply for Basic Access. The tool is not offered to other advertisers. Required Minimum Functionality does not apply.

Tool design

  1. A scheduled job authenticates as a Google Cloud service account invited to the Biography Library manager / Grants client (Standard access, so conversion upload is allowed).
  2. Read: GoogleAdsService.Search for campaign, campaign_budget, keyword_view, metrics.
  3. Write (Grants only): uploadClickConversions with gclid, conversion action, time, and a unique order id. Optional one-time mutateCustomer (auto-tagging) and conversionActions.mutate (create UPLOAD_CLICKS action).
  4. The UI at https://seo.brignole.ch/pubblicita/biography-library reads the database. It never calls mutate on campaigns.

API services called

  • GoogleAdsService.Search (read)
  • ConversionUploadService (uploadClickConversions)
  • CustomerService.MutateCustomer once, auto-tagging only
  • ConversionActionService.Mutate once, if the upload action does not exist

We do not call CampaignService, AdGroupAdService, or other mutate methods to change ads.
